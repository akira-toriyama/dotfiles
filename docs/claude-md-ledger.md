# CLAUDE.md rule ledger (global)

Target = **the global CLAUDE.md** (source: [`chezmoi/private_dot_claude/CLAUDE.md`](../chezmoi/private_dot_claude/CLAUDE.md) → distributed to `~/.claude/CLAUDE.md`).
Each repo's CLAUDE.md (including dotfiles' own [`CLAUDE.md`](../CLAUDE.md)) is out of scope — make one in the same format under that repo's docs/ when the need arises.

Purpose (furrow t-gqd5, agreed in the 2026-07-26 sparring session):

1. **Tell apart rules that rely on prose from rules already enforced by a mechanism** — the 📖 rows are exactly the mechanization candidates (but mechanization follows rule of two — only to prevent recurrence of an already-hit failure).
2. **Put who moves for each rule into one table** — Claude's move / the user's move / mechanism.
3. **Enumerate the user's moves**.
4. **A record of deleted rules** (from the 2026-07-28 zero-based restructure onward) — what was cut, why, and the revival condition.

**Rule bodies are not transcribed here** — the canonical source is each section of the global CLAUDE.md (transcription is where drift starts). This table holds only "who acts, and how it is enforced". The deletion log alone is the exception (its canonical source is gone, so this is the only record left).

## Legend of marks

| Mark | Meaning |
|---|---|
| 🔒 | **Enforced by a mechanism** — a violation is stopped mechanically / the correct state is produced automatically |
| 🟡 | **Half-mechanized** — a mechanism exists, but it is warn-only, after the fact (post-push), or partial coverage |
| 📖 | **Relies on prose** — firing depends on Claude reading and remembering |
| 🙅 | **Out of enforcement scope** — a permission, a discretion, or a judgment norm, where no machine-stoppable "violation" can be defined |

### Mechanisms for this ledger itself (2026-07-28 onward)

- **The CLAUDE.md size ceiling (11,500 bytes), the ban on pinning a concrete model ID, ledger sync (a PR that touches CLAUDE.md touches the ledger too. escape = commit footer `Ledger-unchanged: <理由>`), and glossary sync (a PR that touches CLAUDE.md or skills/ touches docs/glossary.md too. escape = commit footer `Glossary-unchanged: <理由>`)** are enforced 🔒 by the lint gate claude-md-guard ([scripts/claude_md_guard.py](../scripts/claude_md_guard.py), run on every PR in CI's `lint` job). Every one of them prevents recurrence of an already-hit failure (21× bloat, a drifted pin, PR #274's missed ledger update, PR #273's missed glossary follow-up on the same day), so all of them fit rule of two.

## The user's moves (list)

Operations that cannot be mechanized, and that Claude cannot initiate.

### From the global CLAUDE.md (common to every repo)

- **`/effort ultracode` at session start** — cannot be made permanent. Once, in a session that needs fan-out.
- **Switching `/model`, and issuing 「これ Fable で」** (route this to Fable) — Claude cannot change the main-loop model.
- **Running sudo outside a VM (on the host)** — Claude goes as far as presenting the command.
- **Adjudicating preference, risk acceptance, and product decisions** — answering the one-at-a-time questions, delegating with 「残り全部推奨で」 (settle the rest at the recommended values).
- **The GO to start work** — a reply to a question, a status share, or a consultation is not a GO.
- **Deciding canary / fleet progression** — the canonical source for the stages is fleet-change-policy.md.

### From dotfiles' repo CLAUDE.md (moves for this repo only)

- **Running `darwin-rebuild switch` / `--rollback`** — it needs sudo, so Claude goes as far as presenting the command (rule 2).
- **Explicit instruction for destructive git** — force push, history rewriting, and amending an already-pushed commit only when the user says so explicitly (rule 4).
- **Deciding on a PR merge (a repo that has not declared Claude-led operation)** — in dotfiles, rule 5 lets Claude merge.

## Operations

- In a PR that adds, changes, or deletes a rule in the global CLAUDE.md, **update this ledger's row (the deletion log for a deletion) in the same PR**. The canonical source for this obligation is the "When changing the prose of the global CLAUDE.md or a skill" section of [dotfiles/CLAUDE.md](../CLAUDE.md). Enforcement is the `claude-md-guard` gate in `scripts/lint` (the escape is the commit footer `Ledger-unchanged: <理由>`).
- Wherever the global CLAUDE.md **refers to a real dotfiles filename bare**, update the reference in the same PR when the file is renamed. Enforcement is `FLEET_CLAIMS` in `scripts/lint`'s `doc-paths` gate (`scripts/doc_paths.py`), which looks both ways — that the value's path exists, and that the key is still mentioned in the document. **Which names are covered is not copied into this ledger** (`FLEET_CLAIMS` is the machine canon). A count of "6 places" used to be written here, but when the zero-based restructure reduced the references the number stayed behind and turned into a lie.
- Of the 📖 rows, only the mechanizations that satisfy rule of two get turned into tasks.
